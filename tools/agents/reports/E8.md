# E8 — relatório: exemplo 1 (`ola`) do README marcado como trecho do golden

## O que mudou

Arquivo único: `README.md`.

- Bloco `//keel` do exemplo 1: corpo trocado pelas linhas 1-8 de
  `golden/cases/028-readme-main/ola.k`, copiadas com `sed -n 1,8p`. Marcador
  `<!-- golden: cases/028-readme-main/ola.k:1-8 -->` antes da cerca. A assinatura
  passou a `pub int main(int argc, char **argv)`, como no golden.
- Bloco `//C gerado` (`ola_main`): corpo trocado pelas linhas 7-11 de
  `expected/c23/ola.c`, marcador `expected/c23/ola.c:7-11`. O `#include <stdio.h>`,
  o comentário do wrapper e o `int main(void)` saíram deste bloco.
- Segundo bloco `//C gerado` logo depois (unidade de entrada): linha 3 de
  `expected/c23/main_ola.c`, marcador `expected/c23/main_ola.c:3-3`. A rotulagem
  `//C gerado` foi mantida, porque `test/docs.py` só ignora essa primeira linha
  com esse rótulo.
- Prosa após os blocos: "o wrapper `main` fornece a entrada do programa" virou
  "o wrapper `main`, numa unidade à parte (`main_ola.c`, gerada por `--main ola`),
  fornece a entrada do programa; ele repassa `argc` e `argv`, por isso `main` de
  módulo os recebe". O resto da frase ficou igual.

Nenhum outro ponto do README foi alterado. `golden/`, `test/` e `tools/cgen/` não
foram tocados.
